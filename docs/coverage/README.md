## What is counted

An **API resource** is what the generator finds in the vendor's OpenAPI spec (`hack/gen/vendor.yaml` `specs`): a path you can create and read (`crud`), a path written in place and read back (`upsert`), or a settings path you read and write (`settings`). The spec's paths are read as published; resources that only a GraphQL API or SQL reaches, or that the spec does not describe, are not counted.

- **ours**: a kind of this repository calls the resource's path, or stands in for the Terraform type matched to it.
- **official**: the Terraform type matched to the resource is one the vendor's own operators cover (the gaps file's `covered` list). This repository's gaps file has none, so nothing counts as official here.
- **ours beyond official**: ours, and not official.
